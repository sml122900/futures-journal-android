## 세션 — Emergency Brake 트리거 메시지 표시 개선

---

## 배경

서버 Emergency Brake 시스템이 통계 기반 → 사용자 정의 룰로 재설계됨. FCM 페이로드에 트리거 타입 배열 대신 실제 발동 메시지 배열이 추가됨. 오버레이 화면에서 사용자가 "왜 경고가 왔는지" 명확히 보여줄 수 있도록 업데이트.

---

## 변경 내용

### 1. strings.xml

트리거 타입별 한국어 레이블 6개 추가:
- `trigger_max_total_position`: 총 포지션 규모 한도 초과
- `trigger_no_trade_window`: 매매 금지 시간
- `trigger_recurring_no_trade`: 반복 금지 시간대
- `trigger_max_single_loss`: 포지션 손실 한도 초과
- `trigger_min_interval`: 최소 매매 간격 위반
- `trigger_max_single_size`: 1회 진입 한도 초과

### 2. EmergencyPayload.kt

`triggerMessages: List<String>?` 필드 추가. 새 서버 시스템에서 실제 발동 메시지를 내려줌 (예: "1회 진입 사이즈 150 USDT가 한도 100 USDT 초과").

### 3. OverlayService.kt

`buildTriggerText(payload)` 함수 추가:
```
1순위: triggerMessages (실제 발동 메시지 배열)
2순위: triggers (타입 배열 → strings.xml 한글 레이블로 변환)
3순위: 기존 symbol × sizeMultiplier 배 표시 (구 시스템 fallback)
```
`showOverlay()`에서 context_text에 이 함수 결과를 표시.

## 하위 호환성

- `triggerMessages`가 null이면 `triggers` 타입 배열로 fallback
- `triggers`도 비어있으면 기존 사이즈 배수 표시 fallback
- 구 버전 서버와도 정상 작동
